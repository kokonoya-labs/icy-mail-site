ICY Mail プライバシーポリシー

最終更新日: 2026年9月10日

本プライバシーポリシーは、ICY Mailにおける Googleユーザーデータその他の情報の取り扱いについて説明します。

1. ICY Mailについて

ICY Mailは、ユーザー自身のGoogleアカウントに接続し、 Gmailの閲覧、送信、整理などを行うための デスクトップメールクライアントです。

2. Googleアカウントへのアクセス

ICY MailはGoogle OAuthを使用してGoogleアカウントへの アクセス許可を取得します。

ICY Mailは、ユーザーがGoogleの認証・同意画面で明示的に許可した 権限の範囲内でのみGoogleユーザーデータへアクセスします。

3. アクセスするGoogleユーザーデータ

ICY Mailは、メールクライアント機能を提供するために必要な範囲で、 Gmailに保存されている以下の情報へアクセスする場合があります。

  • メールメッセージおよびその内容
  • 送信者、受信者、件名、日時などのメール情報
  • メールに関連する添付ファイル
  • ラベル、既読・未読状態などのメールボックス情報
  • メールの送信に必要な情報
  • 接続されたGoogleアカウントを識別するために必要な基本情報

4. Googleユーザーデータの利用目的

ICY MailがGoogleユーザーデータを利用する目的は、 ユーザーにメールクライアント機能を提供することに限定されます。

具体的には、以下の目的で利用します。

  • メールを取得してユーザーに表示すること
  • ユーザーの操作に基づいてメールを送信すること
  • メールの状態やラベルなどを表示・管理すること
  • ユーザーが選択したメールクライアント機能を実行すること
  • Googleアカウントとの認証状態を維持すること

5. Googleユーザーデータの保存

ICY Mailがメールクライアント機能を提供するために Googleユーザーデータを保存する場合、 その保存は当該機能を提供するために必要な範囲に限定します。

OAuth認証情報についても、 Googleアカウントとの接続を維持するために必要な範囲で保存します。

6. Googleユーザーデータの共有および販売

ICY MailはGoogleユーザーデータを販売しません。

Googleユーザーデータを広告、リターゲティング、 パーソナライズ広告、信用評価、融資判断などの目的で使用しません。

Googleユーザーデータを第三者向けの機械学習または AIモデルの作成、学習、改善のために使用しません。

法令への対応などGoogle API Services User Data Policyで 認められている場合を除き、 メールクライアント機能の提供と無関係な第三者へ Googleユーザーデータを共有しません。

7. 人によるGoogleユーザーデータへのアクセス

Google API Services User Data Policyで認められる場合を除き、 ICY Mailの開発者その他の第三者がユーザーのメール内容を 閲覧することを目的としてGoogleユーザーデータへアクセスすることはありません。

8. Limited Use

ICY MailによるGoogle Workspace APIから取得した情報の利用は、 Google API Services User Data Policy （Limited Use requirementsを含みます）に従います。

9. セキュリティ

ICY Mailは、Googleユーザーデータおよび認証情報について、 不正アクセス、漏えい、紛失、改変などを防止するため、 合理的かつ適切な安全対策を講じます。

10. アクセス権の解除およびデータの削除

ユーザーはICY MailからGoogleアカウントとの接続を解除できます。

また、Googleアカウントのサードパーティ接続管理機能から ICY Mailに付与したアクセス権を取り消すことができます。

ICY Mail内に保存されたアカウント情報または関連するローカルデータは、 ICY Mailのアカウント削除・データ削除機能、またはアプリケーションデータの 削除によって削除できます。

11. 本ポリシーの変更

ICY MailにおけるGoogleユーザーデータの利用方法を変更する場合、 必要に応じて本プライバシーポリシーを更新します。

新しい目的でGoogleユーザーデータを利用する場合は、 必要な通知およびユーザーの同意を取得したうえで利用します。

12. お問い合わせ

本プライバシーポリシーに関するお問い合わせは、 Google OAuth同意画面に表示されるサポートメールアドレスまで ご連絡ください。
