ICY Mail

ICY Mailは、Googleアカウントに接続してGmailを利用するための デスクトップメールクライアントです。

主な機能

ICY Mailは、ユーザー本人のGoogleアカウントへの許可に基づき、 メールの閲覧、送信、整理などのメールクライアント機能を提供します。

GoogleアカウントへのアクセスにはGoogle OAuthを使用し、 ユーザーが許可した範囲でのみGoogleユーザーデータへアクセスします。

Googleユーザーデータの利用

Googleから取得したユーザーデータは、 ICY Mailのメールクライアント機能を提供するためにのみ使用します。

Googleユーザーデータを販売、広告、広告ターゲティング、 信用評価、または第三者向けAIモデルの学習目的で使用することはありません。

ICY MailによるGoogleユーザーデータの利用は、 Google API Services User Data Policyおよび Limited Use requirementsに従います。
